# Nokia Snake Game

A responsive classic Nokia-inspired Snake game made with only:

- HTML
- CSS
- Vanilla JavaScript

## Features

- Red snake on a dark-blue display
- Snake grows after eating food
- Touching the snake's own body/tail ends the game
- Passing through any screen edge makes the snake appear on the opposite side
- Start Game screen
- Game Over / Play Again screen
- Score and persistent Best Score using localStorage
- Keyboard controls: Arrow Keys or WASD
- Mobile swipe controls
- On-screen touch controls
- Pause button
- Responsive desktop, tablet, and mobile layout

## Run

Open `index.html` in a browser. No framework, build tool, or server is required.
